# site-work

Общая полка сайтов. Один репозиторий, много проектов. У каждого проекта своя папка и, когда появится публикация, своя ссылка.

## Как раскладывать

Тема — папка на верхнем уровне. Сайт — папка внутри темы.

```
beauty/                 салоны, парикмахерские, ногти
  mega-strizhka/        сеть МЕГАстрижка, Пермь
```

Новая тема — новая папка рядом с `beauty`. Новый сайт той же темы — новая папка внутри неё, не внутрь чужого проекта.

## Ссылки

Адрес публикации пишется в [catalog.json](catalog.json), поле `url`. Папку из-за ссылки не переименовываем.

## Новый сайт

1. Создать `тема/короткое-имя/`.
2. Положить самостоятельный проект со своим `package.json`.
3. Добавить строку в `catalog.json`.
4. Не коммитить `node_modules`.
