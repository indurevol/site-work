# Проект: МЕГАстрижка

При создании и правке сайта держать стиль компании, а не подменять его нейтральным шаблоном.

МЕГАстрижка — тёплый салон. Акцент медный оранжевый: `copper` `#c4623d`, `copper-deep` `#8e4128`. Фон `paper` `#f3eee6`, карточки `surface`, подложки `sand` `#efe4d6`, текст `ink`. Заголовки — Cormorant Garamond, текст — Manrope.

После сборки пройтись по гостевым страницам и убрать слова черновика: «для презентации», «чек-лист нового сайта», «витрина», «демо», «заглушка», «этот браузер». Гость видит речь салона. Чек-лист и пояснения к сборке живут только в списке инструментов, не в меню и не в подвале.

Админка на тех же цветах, что и сайт. Активный раздел и включённый переключатель — медь. На узком экране разделы переносятся, страница не уезжает вбок.

Общие правила такой полки сайтов:

- У каждого проекта свой адрес. Главная репозитория — список, не витрина одного салона.
- Цены, мастера, отзывы и заявки живут в маленькой базе на сервере, за API по HTTPS. Порт базы в интернет не открывать.
- Заявку и отзыв принимает API без ключа. Изменение содержания — с ключом администратора. На учебном стенде ключ можно вшить в админку; в список инструментов это записать, гостю не показывать.
- В админке можно добавить и поправить всё, что гость видит как содержание: филиалы, прайс, акции, мастеров, отзывы, вопросы, телефоны, часы, ссылку записи. Скрытие не удаляет запись. Интеграции внешних сервисов остаются заглушками, пока нет настоящего ключа сервиса.
- Если отправка не дошла, уведомление показать в конце, когда человек нажал кнопку, а не на первом экране.
- После сборки вычистить со страниц для гостя слова черновика.

Для салона красоты дополнительно: мастера и филиалы — данные, не зашитый список. Филиал: название, адрес, район, пометка, оценка, число оценок, ссылка на карту. Мастер: имя, роль, салоны, заметка. Прайс, акции, вопросы, телефоны и часы тоже правятся в админке. Расписание смен не выдумывать.
