# МЕГАстрижка

Витрина сети парикмахерских в Перми: шесть адресов, прайс по открытой карточке 2ГИС, отзывы, заявка и презентационная админка без входа.

Цены не являются офертой. Заявка хранится только в браузере. Живая запись — [YClients](https://n723672.yclients.com/).

Страницы:

- `/` — сайт для гостя
- `/plan` — порядок блоков, общий чек-лист и лист для парикмахерской
- `/admin` — заявки, отзывы, прайс, филиалы и заглушки интеграций
